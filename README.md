# 深鲸工序 · DSH 插件

[![Listed on DSH Plugin Hub](https://dsh-plugin.org/badges/listed.svg)](https://dsh-plugin.org/zh/plugins/feely0208/dsh-design-line)

> 给设计师做的**工序流水线**：把一条完整的活一口气跑完 —— 不是零散小操作。
> 一个包 = **一份内核 + 四个适配器**（Photoshop / AutoCAD / 3ds Max / Blender）。
> 它同时是个**框架**：写一个适配器就能接入新软件，内核一行不用改。

装完在深鲸桌面里多出：「深鲸工序」面板 + `design-line` 技能 + `/工序` 命令。

## 安装

```bash
dsh plugin --profile web add @deepwhale-cn/dsh-design-line
```

装完刷新（或重启）应用，左侧栏会出现「深鲸工序」。也可以直接从官网下载 tgz：
`https://www.deepwhale.org.cn/downloads/deepwhale-cn-dsh-design-line-0.1.0.tgz`

## 三条流水线

| 流水线 | 一条线跑完什么 | 替掉多少 |
|---|---|---|
| **PS · 出图交付** | 收料建档 → 规范命名 → 统一尺寸/画布 → 水印与版权 → 按规格分尺寸导出 → 交付清单 | 半天（30~80 张素材） |
| **CAD · 出图标准化** | 图纸台账 → 备份 + 图层规范化 → 图框与比例 → 标注文字样式统一 → 打印样式 → 批量出 PDF → 图纸目录 | 一天（20~60 张图） |
| **3ds Max · 批渲染交付** | 场景台账 → 规范检查（单位/丢贴图）→ 材质灯光相机套用 → 渲染参数 → 逐机位批量渲染（可断点续跑）→ 命名归档 → 出图清单 | 一天（10~30 机位） |

**判据只有一条**：跑完能替掉设计师**半天到一天**的真实工作。

## 怎么用

**① 面板（点着跑）**：左侧「深鲸工序」→ 选流水线 → 填参数 →【① 先落盘审阅】→【② 开始跑】→【③ 校验回执】。

**② 一句话（Agent 跑）**：直接说「把这批图按客户要的三个尺寸出成交付，右下加水印」，
Agent 会读 `design-line` 技能，按同一条工序执行。

**③ 不装 DSH 也能用**：同一套流水线可以导出双击就跑的脚本给设计师
（PS → `.jsx`；CAD → `一键出图.bat`；3ds Max → `批渲染.bat`），素材不出门、断网可跑。

## 三条规矩（产品的一部分，不是文档装饰）

1. **先落盘审阅，再执行**：每一步「做什么 / 调什么接口 / 怎么验证 / 失败怎么回退」先写给你看。
2. **判据在产物那边**：跑完不看脚本自报，看产物 + `回执.md`（含 SHA-256 指纹与"是不是本次生成"）。
3. **改图不可逆的事，没有备份不动手**：CAD / Max 先备份；备份不成功就停手。

## 安全与边界

- **不联网**：全程本机，素材不出门（交付的脚本里没有任何联网写法）
- **有上限**：素材数上限、日志 8MB 封顶、跑前磁盘 < 1GB 拒绝开跑、大数量先确认
- **可核对**：每次运行产出 `回执.md`（交付凭证），客户可以用一条命令自己验：
  `node 回执模块/verify.mjs <运行目录>` —— 重算指纹、核对"是不是这次的"
- **过程痕迹与交付物分开**：`交付包/` 给客户，`_运行日志.txt` / `异常.md` 给设计师

## 版本策略

**不锁版本**：接口只选厂商自带、老而稳的那层 —— PS 用 ExtendScript、CAD 用 AutoLISP、
3ds Max 用 MAXScript；启动先做能力探测，缺能力**明确说缺什么**，不崩。
AutoCAD 从 2004 到 2026、3ds Max 从 2012 到 2024、PS 从老版本到 2024 都在覆盖目标里。

## 包内结构

```
lib/        插件半边（index.js = 宿主侧：技能/命令/HTTP 出口；client.js = 面板 UI）
skill/      技能正文（Agent 读的就是它）
bin/cli.mjs 命令行入口（不装 DSH 也能直接用）
内核/       与软件无关：意图 → 工序 → 落盘 → 执行 → 校验 → 回执 → 回放
适配器/     每个软件一小份：photoshop / autocad / threedsmax
流水线/     三条工序定义（单一事实源，文档由它渲染）
回执模块/   过程回执 + 独立校验器
```
