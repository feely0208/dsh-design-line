# 回执模块（过程回执 / 可核对凭证）

> **一个概念**：自动化产出的交付物，附一份**回执**；**任何人都能拿去核对**，不需要信任产出方。
> 回答三个问题：**是这次的？怎么来的？边界在哪？**

出自 DSec 威胁模型的结论「只看结果的校验，骗得过」——
所以回执不只记"结果对不对"，还记"这一步走的哪条路、哪些降级、边界是多少"。

## 一、产物

| 文件 | 给谁 |
|---|---|
| `回执.json` | 机器：指纹、字节、状态、可被下游/脚本消费 |
| `回执.md` | 人：可以直接给客户看的一页**交付凭证** |

`回执.md` 里自带一行"怎么自己验"，客户拿到的不是一句口头保证，而是一条能跑的命令。

## 二、产出方怎么接入（4 个函数）

```js
import { 新建回执, 记步骤, 采产物, 收尾, 落盘 } from "../回执模块/module.mjs";

const r = 新建回执({
  产品: "深鲸工序", 流水线: "ps-出图交付",
  宿主: { 软件: "Adobe Photoshop 2024", 版本: "25.4.0", 通道: "open -g -a" },
  意图摘要: { 客户: "深鲸", 规格: "2 档" },
  边界: { 最大文件数: 500, 磁盘预检: "< 1GB 拒跑" },
  运行目录, 开始时间: 产出那一刻的 ISO 时间,   // ⚠️ 不是"写回执的那一刻"
});

记步骤(r, { 编号: "S1", 名称: "收料与建档", 状态: "已完成", 耗时毫秒: 573, 分支: "页面设置序列", 降级: [...], 检查: [...] });
采产物(r, 运行目录, ["交付包/交付清单.csv", ...], Date.parse(产出时间));
收尾(r, "全部执行并校验通过");
落盘(r, 运行目录);
```

> ⭐ **`开始时间` 必须传"产物是哪一次跑出来的那一刻"**：在已有产物的目录上做"全跳过"的重跑，
> 如果拿"现在"当开始时间，回执就会把上次的产物谎报成这次跑的 —— 校验器会当场揭穿（我们踩过）。

## 三、核对方怎么用

```bash
node 回执模块/verify.mjs <运行目录> [--json]
```

它只读磁盘 + 回执，**不 import 产出方的任何代码**。判据：

| 判据 | 抓什么 |
|---|---|
| 回执必填字段齐、步骤与产物非空 | 空壳回执 |
| 结论 vs 步骤状态/校验结果是否自相矛盾 | 「结论说全通过，其实有步骤失败」 |
| 每个产物存在 / 字节数一致 | 产物被删、被替换 |
| 每个产物 **SHA-256 一致** | 内容被改过（哪怕字节数一样） |
| 每个产物 mtime ≥ 回执声明的产出时间 | 拿旧文件冒充新产物 |
| 磁盘上"存在但没申报"的产物 | 偷偷多塞东西 |

退出码：`0` 通过 ｜ `1` 有问题 ｜ `2` 没有回执。

## 四、已验证的篡改场景（都当场抓住）

| 场景 | 结果 |
|---|---|
| 改 1 个字节（字节数不变） | ❌ 指纹不符（回执 `8bb1ce57a45b` / 实际 `5f5f5c714a8d`） |
| 把 mtime 改回昨天 | ❌ 不是这次生成的（`2026-10-13T04:00Z` < `2026-10-14T11:57Z`） |
| 删掉一个产物 | ❌ 产物缺失 |
| 全跳过式重跑（没产出新东西） | ✅ 回执沿用上次产出时间，仍然自洽（不谎报） |
| 只重跑某一步（部分重跑） | ✅ 取"最早一次产出"，不误伤更早产出的产物 |

## 五、别的产品线怎么用（同一套，不重写）

| 产品线 | 回执里放什么 |
|---|---|
| 设计交付（本插件） | 每个规格的成图 + 交付清单 + 降级项（水印降级等） |
| 律师端 / 脱敏工具 | 输入→输出的脱敏记录、处理规则版本、**不含案件内容本身** |
| 内容分发 | 发布凭证：发到哪个平台、平台侧链接、发布时刻 |
| 我们自己的多 Agent 协作 | 子代理产出即回执；Lead 用 `verify.mjs` 复核，不看自述 |

## 六、它**不**证明什么（诚实清单）

- ❌ **不证明产物"来自哪张素材"**：现在只证到"是这次的、内容没被改"。要做需要图像指纹/内容比对，成本高一档。
- ❌ 不防"产出方在生成时就造假"：回执由产出方写，它能在写的时候就把假话说圆。
  真正的对抗性场景要"策略执行点放在产出方改不到的地方"（见《深鲸通用工程原则》）。
- ❌ 不是数字签名：没有密钥、没有第三方时间戳。要抗"产出方事后整体重写回执+产物"，得上签名（待定）。
